A proposed learning sequence

Plan / 23 Oct 2026

Teaching mode is not yet implemented. It is not included in the current release. This page describes the proposed experience and first pilot.

One workflow. Growing independence.

From “show me” to “let me try.”

01

Show me

Watch an explained demonstration. Pause to understand what each step does and why it matters.

Evidence: the demonstration ran.

02

Guide me

Use the platform yourself. Get contextual instructions and hints while Daedlo observes the agreed milestones.

Evidence: practice with assistance.

03

Let me try

Complete a fresh task without step-by-step prompts. Review the result and any help you needed afterward.

Evidence: independent completion, when observed.

Watching a demonstration would not count as independent completion. Each experience would keep its own evidence.

Help me now Later

Guidance for an unfamiliar or occasional task during everyday work. A later extension, after the first training pilot.

First proposed lesson / Roots

A draft you can
come back to.

Journal draft retention

Learn how to leave Journal, visit other parts of Roots, and return to the draft you were working on.

THE TAKEAWAY

Draft retained does not mean experience saved.

PROPOSED LESSON OUTLINE

  1. 01

    Prepare a Journal draft

    Use training data to set the date, notes, and rating. Keep Strain as “Not specified” and leave the experience unsaved.

  2. 02

    Take a trip away

    Visit Home, then Profile. Notice that navigating the platform is a different action from saving an experience.

  3. 03

    Return to Journal

    Compare the draft fields with the values you entered. The lesson would check the observed contents.

  4. 04

    Explain what happened

    Recognize the retained draft and its unsaved status. Then repeat with a fresh draft, without hints.

Real workflow. Proposed lesson.

The workflow comes from recorded work with the original Roots driver on 26–27 September 2026. Those records cover date, notes, rating, and selected strain surviving Home → Profile → Journal. This is historical application evidence, not a teaching-mode test or a result for a new Daedlo teaching integration.

The original recipe also created a private strain; it left the Journal experience unsaved. The proposed lesson would keep Strain as “Not specified” and would not create a strain. This reduced variant still requires fresh acceptance. The lesson would run in an isolated training environment with disposable data.

Build on a shared understanding

The same task.
A new way to learn it.

Daedlo already runs authored browser flows and supports explained, paced presentations. Teaching mode would add learning objectives, guided practice, and feedback to an accepted application workflow.

Application-specific integration would still be required: a Rust state model and JavaScript adapter, plus lesson content reviewed by someone who knows the platform. The team defines correct behavior and the evidence that demonstrates it.

Learner actions need their own observation and assessment path. The teaching plan would preserve the current execution safeguards and keep application success separate from learning progress.
