What this run covers

The editor and its persistence were exercised with disposable synthetic data. The topology is an authored 3D simulation. Simulated jobs and performance are outside this check. The integration also passed 13 Rust checks and 7 Node checks.

The public ZIP matched its published SHA-256. The installation used fresh dependency caches for npm, Cargo and Chromium with existing Node.js 22.20.0 and Rust 1.96.0 toolchains. The public runtime, crate and tools retained their original bytes.

A customer-authored Rust state model and JavaScript adapter connected the editor. The first run exposed issues with readiness, selectors, invalid input and save observation. This recording follows the corrections.

This acceptance covers one flow on macOS arm64. Linux, Windows and Claude Code remain unverified for this run. Clean OS installation, automatic skill discovery, independent human onboarding, concurrent editors and injected save failures were outside its scope.
