THE INSTALLATION BEHIND THE RUN

The public kit.
Fresh dependency caches.

The downloaded ZIP matched its published SHA-256. We installed the runtime, Chromium and Rust dependencies into new, empty caches, using existing Node.js 22.20.0 and Rust 1.96.0 toolchains. The public runtime, engine crate and tools stayed unchanged.

A customer-authored Rust state model and JavaScript adapter connected this application. The first run exposed integration issues around readiness, selectors, invalid input and observing a save; those were corrected and checked before this completed run.

This is one verified flow on macOS arm64. Linux, Windows and Claude Code remain unverified for this acceptance. A clean OS installation, automatic skill discovery, independent human onboarding, concurrent editors and injected save failures were not tested.
