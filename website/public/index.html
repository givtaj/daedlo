Integration guide

Bring your application.

The Swagger UI integration runs allowed requests from a bounded subset of OpenAPI 3.0, 3.1 and 3.2 JSON. For other browser flows, application-specific integration connects your Rust state model and JavaScript adapter. Authored checks run locally without a model API key.
