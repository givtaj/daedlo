# 0.1.1-rc.4 — portable installation and recoverable CLI shutdown

This developer preview packages the local QA runtime for agent-assisted use in an
existing codebase. Follow the [download and mount guide](../releases.md). Repository
access is required while distribution remains private; an authorized maintainer
can also deliver the exact assets and trusted receipt privately.

## Changes

- A separate dependency-free tools package includes release discovery, verified
  downloads, archive-store selection/rollback, contracts and the complete agent
  skill. Consumer commands work outside the driver source checkout.
- The CLI waits for active execution and run cleanup before exporting its report,
  preserving the final command's effect evidence and actual resource status.
- Failed owned cleanup retains retry handles and signal handling. A fresh signal
  retries failed cleanup without repeating application effects. Interrupted
  startup and report-write errors preserve cleanup responsibilities.
- The install guide shows a separate customer QA directory, prerequisites, private
  download access, local launch and explicit candidate promotion. Packaged docs
  are checked for missing local references.
- The isolated SeeRuntime integration records a second real application's tested
  flow and the limits of its rc.2/rc.3 comparison. It is historical customer
  evidence, not fresh rc.4 application acceptance.

The runtime and Rust crate keep protocol 1. This release changes the CLI lifecycle;
version/protocol compatibility alone is not evidence that a customer's model and
adapter still work. Test a new exact pair beside the accepted integration before
changing its pins or launcher. Local rc.3 bytes remain historical candidates and
are not reused as this release.

## Evidence and boundaries

[Source verification](../verification.md) records regression failures before fixes
and actual source checks. The [GitHub release](https://github.com/givtaj/browser-driver/releases/tag/v0.1.1-rc.4)
and its `VERIFICATION.md` asset bind the final clean commit, existing CI run,
installed-package checks and exact archive digests after source freeze. A source
note alone does not confirm publication.

The release contains the four-file runtime/crate bundle, three portable-tools
assets, the standalone skill archive and its checksum inventory, and the final
verification receipt. It is not published to npm or crates.io. The existing CI
configuration is unchanged.

There is no WBF integration in this release. Installation prepares the tools;
an agent still authors or reuses the customer's Rust model, guarded adapter and
agreed flows. Windows, automatic skill discovery in both agent hosts, and arbitrary
framework compatibility remain unverified. No everyday Roots or SeeRuntime
installation is replaced. The viewer is local. Cloudflare, WorkOS/Google login and
Stripe billing remain a documented later portal phase.
